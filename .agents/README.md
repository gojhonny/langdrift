# Agent harness

`.agents/` is the agent operating layer.

- [context.md](context.md) is project knowledge. Domain modeling edits only its vocabulary region.
- [skills/](skills/README.md) holds reusable procedures. Read a skill's `SKILL.md` before applying it. [skills/SOURCES.md](skills/SOURCES.md) records upstream origin and local adaptations.
- [workflow/](workflow/README.md) is the canonical Spec-driven Development lifecycle. [workflow/CYCLE.md](workflow/CYCLE.md) owns transitions.
- [guardrails/](guardrails/README.md) is reserved for approved agent-operating constraints. None are implemented.
- [hooks/](hooks/README.md) is reserved for executable mechanisms. None are implemented.
