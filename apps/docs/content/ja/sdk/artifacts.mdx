# アーティファクト

アーティファクトには、検証済みのメタデータ、ソースパス、明示的な参照、リソース名があります。Markdown のアーティファクトは、本文のテキストも保持します。

## パッケージが所有する場所

プロトコルバージョン 1 が検出するのは、次の再帰的なソースグロブだけです。

- Vision: `research/**/*.md`、`prd/**/*.md`、`context/**/*.md`
- Loop: `triage/**/*.md`、`design-document/**/*.md`、`spec/**/*.md`、`ticket/**/*.md`
- Evidence: `adr/**/*.md`、`audit/**/*.md`、`record/**/*.json`、`drift/**/*.json`

すべてのグロブは、`.drifts/<pillar>/` を起点とします。`evidence/audit/runs` や `evidence/audit/reports` のような入れ子の `audit` パスは、`audit` のグロブに含まれます。任意のソースグロブはサポートされません。

9 つの文書ファミリーには Markdown を使います。Record と Drift Event のエンベロープには JSON を使います。検出の間、メタデータの `type` はソースディレクトリと一致しなければなりません。

## 解析

```ts
parseArtifact(text: string, artifactPath: string): ParsedArtifact
```

`parseArtifact` は `.md` と `.json` のパスを受け付けます。メタデータを検証し、`vision.prd` のような柱のリソースを導出し、明示的な参照を集め、元のアーティファクトパスを返します。

Markdown の場合、`body` は閉じるフロントマター区切りのあとのテキストです。JSON の Record と Drift Event の場合、`body` は空です。未対応の拡張子、不正な入力、欠けているフロントマター、または 1 MiB を超えるアーティファクトは、コード `ARTIFACT_INVALID` の `LangDriftError` になります。

## 検出

```ts
await discoverArtifacts(root, {
  maxFiles: 1000,
  maxDirectories: 1000
})
```

両方の上限は既定で `1000` であり、正の安全な整数でなければなりません。呼び出し元は、異なる上限を明示的に選べます。ファイルの読み取りは 1 MiB に制限されます。

検出は、次のように動作します。

- パッケージが宣言した `.drifts` の場所だけを訪問します
- 処理の前に、ディレクトリエントリをソートします
- ドットで始まるエントリと `node_modules` をスキップします
- 存在しないアーティファクトディレクトリは無視します
- シンボリックリンクをたどらず、拒否します
- ディレクトリトラバーサル、絶対パス、バックスラッシュ、制御文字、隠しパスセグメント、依存関係ディレクトリを拒否します

リポジトリ全体は走査しません。変化していないファイルシステムに対する結果は決定論的です。パッケージの場所には宣言された順序があり、各ディレクトリはソート順に走査されます。

検査している間、信頼できないプロセスがローカルプロジェクトの内容を変更してはなりません。
