# Linear と Obsidian

両方の連携の機能は、現在 `interface-only` です。

セットアップは `--linear` / `--no-linear` と `--obsidian` / `--no-obsidian` を受け付けます。これらのフラグが書き込むのは、ローカルのプロジェクト設定にある対応する `enabled` 真偽値だけです。認証情報は要求せず、接続も確立しません。

SDK に共通する唯一のプロバイダー拡張は `RecordSourceAdapter` であり、その `readRecords()` メソッドは Record の非同期ストリームを返します。Linear または Obsidian 専用のアダプターは実装されていません。

現在、次のものはありません。

- プロバイダー認証
- API クライアント、または保管庫クライアント
- ポーリング、Webhook、ファイル監視のランタイム
- プロバイダーへの書き込み経路
- 双方向の同期
- 競合解決や、リンクの自動抽出

アプリケーションは、取り込みインターフェースを別途実装できます。ローカル設定を有効にしても、そのような実装は有効になりません。
