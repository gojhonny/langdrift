# トラブルシューティング

まずエラーの `code` を確認してください。`LangDriftError.issues` には、検証失敗の JSON Pointer パスが含まれます。`SetupError.files` と `.fields` は、セットアップの競合と不足している入力を示します。

## プロジェクトの読み込み

### `PROJECT_NOT_FOUND`

上方向へ探索しても `.git` ルートが見つからなかったか、`.drifts/project.json` がありません。意図した既存のルートを明示的に渡すか、その場所でローカルセットアップを実行してください。

### `PROJECT_INVALID`

プロジェクトファイルの JSON が不正であるか、プロジェクトスキーマと一致しません。手動で確認してください。セットアップは競合する内容を保持し、置き換えません。

### `SCHEMA_UNSUPPORTED`

イベント、アーティファクト、プロジェクト、または推論エンベロープが、`1` 以外のスキーマバージョンを宣言しています。このリリース候補には移行経路がありません。バージョン 1 のスキーマとデータを照合して確認するまで、その番号を変更しないでください。

## アーティファクトと参照

### `ARTIFACT_INVALID`

現在の原因には、次のものがあります。

- JSON の形式が不正である、または `langdrift` フロントマターがないか無効である
- 未対応の `.md` / `.json` の使い方、または型とディレクトリの不一致
- 未知のフィールド、またはその他のスキーマ不一致
- ファイルまたは本文が 1 MiB を超えている
- 検出の上限が無効である、またはファイル数やディレクトリ数の上限を超えている
- ローカルの `(type, id)` 識別子が重複している
- Drift の影響が一貫していない、または Evidence の来歴が欠けている
- GitHub のマージ済みプルリクエストのフィクスチャが無効である

`issues` のフィールドパスを読んでください。パーサーは、見出しやファイル名から、不足している識別子を推測しません。

### `PATH_OUTSIDE_ROOT`

パスが絶対パスである、上方向へたどる、禁止されたセグメントや文字を含む、またはシンボリックリンクに到達しています。プロジェクトの `.drifts` ツリー配下にある、通常の相対パスを使ってください。検出はシンボリックリンクをたどりません。

### 参照の問題

`REFERENCE_NOT_FOUND` と `REFERENCE_CYCLE` は `resolveReferences(...).issues` に返され、例外としては送出されません。明示的に既知の外部識別子を登録するか、正確な型、ID、パスを修正するか、トランスポートの前にローカルの循環を取り除いてください。

## 認証情報とトランスポート

### `CREDENTIAL_MISSING`

参照が `env:NAME` 形式ではないか、環境の値が存在しないか、改行またはヌルバイトを含んでいます。参照だけを渡し、値は実行時の環境に用意してください。

### `REMOTE_UNAUTHORIZED`

注入されたトランスポートが `401` または `403` を報告しました。ルーティング用の `account_id` と `project_id` は認可を与えません。実行時の認証情報と宛先のポリシーを確認してください。

### `REMOTE_REJECTED`

注入されたトランスポートが、別の `4xx` ステータスを報告しました。検証済みのエンベロープと宛先の契約を確認してください。

### `MCP_UNAVAILABLE`

トランスポートは、分類された `4xx` レスポンスなしに失敗しました。ローカルには何もキューに入りません。呼び出し元が用意したアダプターを確認したあとでのみ、再試行してください。

## セットアップ

- `ROOT_INVALID` — `--root` が既存のディレクトリに解決されません。
- `SETUP_ARGUMENT_MISSING` — 非対話の実行では、プロジェクト ID、アカウント ID、名前を指定してください。
- `SETUP_ARGUMENT_INVALID` — 対応しているフラグ、互いに矛盾する真偽値フラグ、組で指定する数値の GitHub インストール ID と `owner/repository` を確認してください。
- `SETUP_CONFLICT` — すべてのファイルのステータスと理由を確認してください。プリフライトは何も書き込みませんでした。
- `SETUP_PATH_CONFLICT` — 管理対象パスがシンボリックリンクであるか、親がディレクトリではありません。
- `SETUP_CONCURRENT_CHANGE` — プリフライトのあとで宛先が変化したため、その内容は保持されました。
- `SETUP_WRITE_FAILED` — 入出力の失敗により作成が中断されました。それより前に作成されたファイルが残ることがあります。確認して再実行してください。

`.drifts/execution` は意図的な競合です。このバージョンは Loop を使い、レガシーの移行は行いません。

安全なアプリケーション診断では、`reportError(error, logger)` がコード、一般的なメッセージ、検証の `issues` を出力します。未知の例外の本文とスタックは省略します。
