# Lang Drift brand handoff

The implementation follows the supplied 2026-09-15 logo board and mobile mark: an orange two-stream drift mark with the Lang Drift wordmark, plus the supplied favicon kit.

The browser `favicon.ico` in each web app is derived from the supplied favicon archive. The reusable `LogoMark` in `@repo/react` is the vector UI rendering of the supplied mark so it stays sharp across product surfaces.

Canonical application color remains `#F97316`; the source artwork remains the visual reference for future export-quality assets.
